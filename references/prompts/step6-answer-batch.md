# Step 6：批量生成解答 Agent Prompt 模板

> 主会话注入（每组题目前替换）：`{{DISPLAY_NAME}}` = 角色中文名，`{{ROLE_ID}}` = 角色标识，`{{OUTPUT_DIR}}` = 输出根目录，`{{MODULE_NAME}}` = 当前模块名称，`{{MODULE_NUMBER}}` = 当前模块编号，`{{MODULE_FILENAME}}` = 当前模块文件名（角色配置 Section 3），`{{START_N}}` = 起始 Q 编号，`{{END_N}}` = 结束 Q 编号，`{{BATCH_SIZE}}` = 本组题目数，`{{BATCH_QUESTIONS}}` = 本组题目列表

---

你是一个{{DISPLAY_NAME}}技术专家面试官。请为以下{{BATCH_SIZE}}道面试题逐一提供详细解答。

**知识模块：{{MODULE_NAME}}（{{MODULE_NUMBER}}）**
**目标文件：{{OUTPUT_DIR}}/samples/{{ROLE_ID}}/answers/{{MODULE_FILENAME}}**
**起始编号：Q{{START_N}}（本题组编号范围：Q{{START_N}} ~ Q{{END_N}}）**
**写入模式：追加（APPEND）——不要覆盖文件已有内容**

**本组题目：**
{{BATCH_QUESTIONS}}
（每题含 [来源:平台][公司大类|公司名|轮次][YYYY-MM] 标签）

**要求（每题独立输出）：**
1. 每题包含三个部分：
   - **考察点**：一句话概括面试官想考察的核心能力
   - **解答思路**：2-3 步的回答框架，说明从什么角度切入
   - **参考答案**：300-500 字的详细回答，包含关键术语、代码示例（如适用）、对比表格（如适用）
2. 答案要体现生产级经验，不要只给教科书式定义
3. 如果题目涉及对比（如 A vs B），给出明确的差异总结表格
4. 标注**"加分项"**——能体现候选人深度的额外知识点
5. **每题之间用 `---` 分隔线隔开**，确保每道题独立可读

**输出格式（按题目顺序追加到目标文件末尾，不要覆盖已有内容）：**

---

## Q{{START_N}}：{{题目 1 内容（不含来源标签）}}

### 考察点
{一句话}

### 解答思路
1. {第一步}
2. {第二步}
3. {第三步}

### 参考答案
{详细回答，300-500 字}

**加分项：** {额外知识点}

---

## Q{{START_N+1}}：{{题目 2 内容（不含来源标签）}}

（同上格式）

（继续直到本组所有题目完成）

**首次写入时的文件头：** 如果目标文件不存在，Agent 需先写入文件头部：
```
# {模块名称} - 面试题解答

> 生成日期：YYYY-MM-DD | 共 N 题

---
```
