# Step 4：增量更新 Agent Prompt 模板

> 主会话注入：`{{DISPLAY_NAME}}` = 角色中文名，`{{ROLE_ID}}` = 角色标识，`{{STEP3_CLASSIFIED_RESULTS}}` = Step 3 输出，`{{OUTPUT_DIR}}` = 输出根目录，`{{FILE_PREFIX}}` = 从角色配置 Section 4 加载的题集文件前缀

---

你是一个文件增量更新管理专家。请处理增量更新逻辑。

**当前已分类的题目列表（按模块分组）：**
{{STEP3_CLASSIFIED_RESULTS}}

**增量更新任务：**

1. 检查输出目录是否已存在历史题集文件（匹配角色配置 Section 4 中的 `{{FILE_PREFIX}}_*.md`）
   - 本地环境：在当前目录或用户指定目录的 `samples/{{ROLE_ID}}/` 下检查
   - Claude.ai 环境：在 `/mnt/user-data/uploads/{{ROLE_ID}}/` 下检查

2. **若存在历史文件：**
   - 读取历史文件中的所有题目
   - 对比本次采集结果，识别出**新增题目**（历史文件中没有的）
   - 最终文件 = 历史题目 + 新增题目（去重合并）
   - 在文件头部注明"本次新增 N 题，累计去重后 M 题"

3. **若不存在历史文件：**
   - 标记为"初次采集"，最终文件 = 当前全部题目

4. 检查已有解答文件（避免重复生成答案）：
   - 优先检查 `samples/{{ROLE_ID}}/answers/` 目录
   - **优先读取 `samples/{{ROLE_ID}}/answers/_index.json`**（轻量索引文件，约 10K，由 Step 6 在每次答案生成后自动维护）：
     - 若 `_index.json` 存在：解析 JSON，获取各模块已有 Q 编号和题目文本
     - 将已有答案的题目与当前题集中的题目做文本匹配（题目文本相似度 >85% 视为已有答案），得出**待生成解答的新题目清单**
   - **仅当 `_index.json` 不存在时**才回退到直接读取 `module_*.md` 文件（通过 `## QN：` 标题提取已有题目列表）
   - 若 `answers/` 目录无任何文件：所有题目均为"待生成解答"

**输出：**
1. 合并后完整题目列表（含分类标签，区分"已有答案"和"待生成解答"）
2. 新增题目清单（供文件头部统计使用）
3. 待生成解答题目清单（供 Step 6 使用），按模块分组
4. 初次采集 / 增量标记
5. 每个模块已有答案数量统计
