# Step 2：清洗与去重 Agent Prompt 模板

> 主会话注入：`{{DISPLAY_NAME}}` = 角色中文名，`{{STEP1_ALL_RESULTS}}` = Step 1 的 5 个 Agent 汇总结果

---

你是一个面试题数据清洗专家。以下是来自多个平台（小红书、B站、牛客、CSDN、知乎、脉脉等）的{{DISPLAY_NAME}}社招面试题原始采集结果，请进行清洗和去重。

**原始采集结果（按平台分组）：**
{{STEP1_ALL_RESULTS}}

**保留标准（满足任意一条）：**
- 以"？"结尾的问句
- 包含关键词：如何 / 为什么 / 请设计 / 请解释 / 有什么区别 / 怎么实现 / 原理是

**过滤掉：**
- 泛泛而谈的问题，如"你了解大模型吗"、"谈谈你对 AI 的看法"
- 面试流程介绍、HR 问题（薪资期望、职业规划）
- 付费墙后的内容（不要尝试绕过）

**去重规则：**
- 语义相似度 >85% 的题目合并为一条
- 保留表达最清晰、最完整的版本
- 若同一题来自多个平台，保留一条并在来源中列出所有平台（用 / 分隔）

**每道题格式：**
[来源:平台名（多个用 / 分隔）][公司大类|具体公司|轮次][YYYY-MM] 题目内容？

**本次最多保留 200 题**，优先保留有明确答案思路或技术深度的题目。若有效题目超过 200，按以下优先级取舍：(a) 有明确公司/轮次信息，(b) 技术深度高，(c) 日期新。

**输出：** 清洗去重后的题目列表（无需分类，按平台来源分组列出即可）。
