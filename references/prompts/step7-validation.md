# Step 7.2：索引校验 Agent Prompt 模板

> 主会话注入：`{{ROLE_ID}}` = 角色标识，`{{OUTPUT_DIR}}` = 输出根目录

---

你是一个文件校验专家。请对刚生成的公司分类文件进行全面校验。

**工作目录：{{OUTPUT_DIR}}/samples/{{ROLE_ID}}/**

**检查 A — 链接有效性（正向校验）：**
遍历 company_index.md 中每个大类下"已采集公司"的所有 Markdown 链接：
- [公司名](company/{大类}/{公司名}.md)
逐一确认链接指向的 .md 文件在 company/{大类}/ 目录下真实存在。
若文件不存在：
  - 检查路径是否正确（大类名拼写错误、公司文件名不一致），修正索引中的链接
  - 如果文件确实未生成，从题集文件中提取该公司题目，补生成公司文件

**检查 B — 反向覆盖率（反向校验）：**
遍历 company/ 目录下所有实际存在的 .md 公司文件，确认每个文件都在 company_index.md 对应大类的"已采集公司"中有链接条目。
- 文件存在但索引中无对应条目 → 在索引中补充"已采集公司"链接，从"待采集公司"中移除
- 文件存在但被错误放入"待采集公司" → 移至"已采集公司"并改为链接格式

**检查 C — 分类与统计一致性：**
- 确认"待采集公司"中不应出现任何已在"已采集公司"中的公司名
- 确认 company_index.md 底部统计表格中"已采集公司数"和"已采集题目数"与实际一致：
  - "已采集公司数" = 该大类下"已采集公司"的链接条目数
  - "已采集题目数" = 该大类下所有公司文件的题目总数
- 确认每个"已采集公司"链接格式为 [公司名](company/{大类}/{公司名}.md)（相对路径，不含完整目录前缀）

**校验失败处理：**
- 自动修正可修复的问题（路径错误、遗漏条目、统计数字偏差）
- 修正后重新确认三项检查全部通过
- 输出校验报告

**输出：**
- 校验结果："全部通过"或"发现 N 处问题，已自动修正：{详细列表}"
