## 6. 面试轮次定义

算法岗位面试轮次与通用工程岗位差异明显：一面以手撕代码为主，二面侧重 ML/DL 理论与项目，而非通用的"基础知识→系统设计"模式。

| 轮次 | 关注点 |
|------|--------|
| 一面 | 手撕代码、数据结构与算法、编程基础 |
| 二面 | ML/DL理论、论文讨论、项目经验、模型设计 |
| 三面 | 系统设计、业务理解、文化匹配 |
| HR面 | 薪资期望、职业动机、团队匹配 |
| 总监面 | 技术视野、前沿方向判断、团队管理 |
| 加面 | 额外加试、深度技术考察 |
| 综合 | 来源中无法明确判断轮次的题目 |
